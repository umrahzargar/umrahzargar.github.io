# Umrah | Interactive portfolio (Version 7)

An editable static portfolio ready for GitHub Pages.

## Preview locally

Extract the ZIP and open `site/index.html` in your browser. The site includes all CSS, JavaScript, illustrations, dashboards and Kashmir gallery photographs locally.

## Publish on GitHub Pages

For a user site at https://umrahzargar.github.io, create a public repository named `umrahzargar.github.io`, upload **the contents of the `site` directory** to the repository root, then use Settings > Pages > Deploy from a branch > main > /(root).

No build step or server-side code is needed.

## Contents

- `index.html` : Four scrolling introduction panels, five illustrated project cards with details, Experience, Education and About Me popup.
- `projects/` : Five project case studies with real figures and explanations grounded in the project's public README.
- `assets/` : Local CSS, JavaScript, illustrations, dashboards and photographs for the Kashmir slideshow.
- `documents/` : Project reports and dissertation materials.

Links to GitHub repositories and Streamlit remain external.

### Editing the Kashmir gallery

Images are in `assets/kashmir-*.webp`. Slideshow order and captions appear in `index.html` and `assets/site.js`.
